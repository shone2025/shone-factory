一些提醒：
1:有些老哥账号可以登录 但用一会就会出现401到情况，那是因为官/方在这两天对系统进行的防护更新，以前是不限制 cli和ide的
登录地址的，但现在进行了限制，主包为了安全以前每3到5个号要切换一个ip 主要ip影响到有巴西、乌/克/兰和哈萨克地区的
解决方案就是申请工单，告诉服务器你常用的ip国家是哪里，系统会在24小时内帮你尽量更新（这个是官方的原因，和账号无关，但
主包为了老哥们都能用上，也是每天在更新账号问题，要个星星鼓励不过分吧）

你把后台关了，整个系统只有前端在运行，所以过了8小时后只有最后一个登录的号能用，其他未同步的号就失效了，需要你点击申请刷新按钮
或者你使用us魔法点击手动刷新 复制账号密码 重新在 终端的droid中输入 /login命令 会弹出窗口让你授权，你复制账号密码去授权就行
如果让你收验证码，那么你自己去登录骨骼邮箱自己收，给你的就是骨骼集团号，不要质疑为啥不是gma后缀，因为g号成本十几块 不可能给你的
做梦！！）
